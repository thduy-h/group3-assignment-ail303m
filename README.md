# AIL303m Group 3 Assignment

A small introductory Python coursework repository demonstrating modules, imports, functions, and a shared program entry point.

## Structure

```text
main.py                 Runs each group member's greeting function
Member/hello_duy.py
Member/hello_minh.py
Member/hello_minhle.py
Member/hello_quocbao.py
```

## Run

Python 3.11 or newer is recommended.

```bash
python main.py
```

## Scope

This is a classroom exercise rather than a production package. It is kept public as a simple record of collaborative coursework.
